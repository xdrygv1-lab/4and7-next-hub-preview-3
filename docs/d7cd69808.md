## 1. 자료 자동 입력

허브 파서(pdf.js·SheetJS, 위하고 소계·합계 처리)를 바탕으로 고쳤습니다. 파일은 브라우저 안에서만 읽고 서버로 보내지 않습니다.

| 개선 | 내용 |
|---|---|
| 연도 머리글 읽기 | «항목 2022 2023 2024», «제7(당)기 2024.12.31» 등 머리글로 열과 연도를 맞춤. KODATA·메트처럼 **오름차순 3년 표**도 바르게 읽음 |
| 좌우로 붙은 표 | «자산 … \| 부채 …»가 한 줄에 있어도 과목별로 나눠 읽음 |
| 서식이 섞인 PDF | 제목이 «재무상태표·손익계산서»인 쪽만 재무로 읽고, 표준재무제표·시산표·처분계산서·제조원가명세서는 제외. **제목 없이 다음 쪽으로 이어지는 표**도 포함 |
| 감사보고서 주석 번호 | «현금및현금성자산(주석9)», «매입채무(주석7,9,15)»의 숫자를 금액으로 읽지 않음 |
| 이름이 다른 과목 | 현금및현금등가물, 주.임.종단기채권, 법정적립금(=이익준비금), 영업이익(손실) 등 |
| 손실 부호 | «영업손실 2억»(양수)과 «(2억)»(괄호) 모두 마이너스 |
| 여러 파일 합치기 | 같은 해가 겹치면 **그 해가 당기인 파일**의 숫자를 우선 사용. 회사 정보·주주명부는 가장 최근 연도 파일에서 가져옴 |
| 3년 열로 받는 과목 | 손익: 매출, 영업이익, 이자비용, 법인세차감전이익, 순이익, 임원급여<br>재무상태: 자산, 유동자산, 현금, 매출채권, 재고, 가지급금, 부채, 유동부채, 매입채무, 단기·장기 차입금, 자본, 잉여금, 이익준비금 |
| 단위 | 원·천원·백만원 자동 인식, 입력은 **백만원**, 콤마 표시 |

## 2. 회사 서류 읽기 (새 기능)

| 서류 | 읽는 것 |
|---|---|
| **세무조정계산서** | 법인명, 대표자, 종목, 사업연도(개월 수 경고), 표지 «제N기»로 설립연도 추정, 재무 당기·전기<br>**주식등변동상황명세서**: 주주명·관계코드(00~10)·출생연도·주식 수 → 주주명부 |
| **DART 감사보고서** (비상장 외감) | 재무제표 표지의 **대표이사(공동대표 포함, 회계법인 대표는 제외)**<br>«1. 회사의 개요»: 설립일, 사업목적, **주주현황**(3가지 표 형식)<br>자본 주석: 발행주식 수, 액면 |
| **법인등기부** | 글자 있는 PDF와 **스캔본** 모두. 스캔본은 글자 인식(Tesseract 한국어)으로 읽음<br>흑백 처리로 노란 위변조 방지 무늬 제거<br>읽는 것: 설립일, 발행주식, 자본금, 대표 생년, 취임·중임, 임원, 사임 여부 |

- 등기부 값(설립·생년·취임·임원)은 다른 서류보다 우선합니다.
- 스캔본에서 읽은 값에는 «틀릴 수 있음» 경고가 붙습니다.
- 주민번호는 출생연도만 쓰고 저장하지 않습니다.

## 3. 비상장주식 가치 (상증법 약식)

| 항목 | 내용 |
|---|---|
| 순손익 | **법인세차감전이익**으로 계산 (팀 결정, 약식). 메트는 당기순이익을 씀 |
| 영업권 | 상증령 59조②: (3년 가중평균 × 50% − 자기자본 × 10%) × 3.7908. 시행규칙 19조① 10% 확인 |
| 영업권 제외 | 상증령 55조③: 사업개시 3년 미만, 부동산 80% 이상, 3년 연속 결손 |
| 평가 방식 | **직접 선택**: 자동 / 3:2 / 2:3 / 순자산 100%. 판단 로직은 아랫줄에 표시 |
| 자동 판단 | 3년 미만 → 순자산 100%<br>부동산 80% 이상 → 순자산과 2:3 중 큰 값 (**54조④ 단서, 2026.2.27 개정**)<br>부동산 50% 이상 → 2:3<br>그 외 → 3:2 |
| 하한 | 순자산가치 80%를 모든 방식에 적용 |
| 부동산 시가 | 시가(기준시가·감정가)를 넣으면 장부 토지·건물을 바꿔 순자산과 부동산 비율을 다시 계산 |
| 일회성 이익 | 자산수증이익은 순손익가치·영업권·미래 추정에서 제외 |
| 최대주주 할증 | 반영하지 않고 단서만 표시 (우리 고객은 중소기업 가정) |
| 연도별 표 | 지금, 1·3·5·10년 후의 세전이익, 순자산, 순손익가치, 순자산가치, 회사 가치, 지분가치 |
| **주주별 지분가치** | 1주당 가액 × 주식 수, 지금과 10년 후 |

**주주명부 처리**
- 아는 주주만 넣어도 되고, 나머지는 «그 밖의 주주(모름)»로 묶습니다.
- 주주명부가 있으면 대표 지분율·특수관계 지분율·타인 주주 수를 주주명부에서 계산합니다.
- 대표가 주주가 아니면 «최대주주» 기준으로 표시합니다.

## 4. 상속세

- 일괄공제 5억, 배우자공제를 **최대(법정상속분, 30억 한도)·최소(5억)** 두 가지로 계산, 신고세액공제 3%
- 개인 재산(부동산·금융·채무)과 가수금 포함, 금융재산공제 반영
- 지금, 1·3·5·10년 후의 상속재산, 상속세, **세후 상속재산, 부담률**
- 최대주주가 법인이면 개인 상속세는 «확인 후 계산»으로 표시

## 5. 신호등과 계정 점검

**신호등 10개**: 회사 가치, 잉여금, 임원보수, 배당, 퇴직금, 가지급금, 유고 자금, 주주 구성, 상속세, 이익 흐름(지분 이동 타이밍)

**새로 넣은 판단 규칙**
- 대표 ≠ 주주 (최대주주가 법인이면 «전문경영인·지주구조 확인»)
- 최대주주가 법인, 관계 모르는 주주, 미확인 지분
- 대표+특수관계인 40% 미만 (가업상속공제 요건), 이익 30% 이상 급감, 3년 연속 증가
- 적자 배당, 7개월 가결산 같은 1년 미만 사업연도 경고
- 유고 자금 = (매입채무 + 차입금) − 현금 (메트 방식, 허브는 부채총계 기준)

**계정 점검 (메트 TIPS 자동화)**
- 연구소는 있는데 연구개발비 0
- 퇴직연금 미적립, 가지급금이 있는데 인정이자 미계상, 가수금
- 자산수증이익(가족법인 증여의제 45조의5)
- 인건비 40% 이상, 법인세 실효세율 낮음, 차입금 과다
- 공동대표 약정, 인증(벤처·이노비즈·메인비즈) 유무 → 담당 자격사 연결

## 6. 영업 연결 (보험 제안 명분)

- **급여·배당·퇴직금 세금 비교**: 예상 퇴직금과 같은 금액을 각각으로 받을 때 세금, 4대보험, 실효 부담률, «퇴직금보다 더 내는 돈»
 - 메트 9.6억 예시와 대조: 급여 3.70억/0.42억, 배당 3.33억/0.75억, 퇴직 1.81억 → 메트와 거의 같음
- **임원 퇴직금**: 취임연도별 한도 배수(2011년까지 1, 2012~2019년 3, 2020년 이후 2), 퇴직소득세
- **가지급금 3년 부담**: 인정이자 4.6%, 법인세 추가(2026 세율), 대표 소득세 추가(상여처분), 퇴직금 상계 가능 여부
- **보험 목표 금액**: 상속세 재원, 퇴직금 재원, 잉여금 적립, 유고 자금
- **AP 질문**: 신호마다 붙음
- 재정심사는 허브 계산기로 연결

## 허브 반영 요청 (우선순위)

1. **주식가치 계산 통일**
 - 허브에 아직 남은 `stockVal`(순자산 × 80%)을 없애고, 3장 방식 하나로 맞춰 주세요.
 - 적용할 곳: 상속세 상자, 컨셉 진단, AP 07단계 문구
2. **상속세 배우자공제**
 - 허브 `inhTax`는 «주식 − 5억»만 계산합니다.
 - B사 예시 기준으로 허브는 약 2배 높게 나옵니다.
3. **파일 읽기 교체**
 - 1·2장 파서를 허브 «재무제표 파일 넣기»에 그대로 옮겨 주세요.
 - DART 상호 검색은 허브의 서버 연결을 그대로 쓰면 됩니다.
4. **신호등 규칙·계정 점검 추가** (5장)
5. **세금 비교표·가지급금 부담표·연도별 표·주주별 지분가치** (3·4·6장)
6. **재무비율 4종** (7장)

## 아직 남은 것 / 확인 필요

- 4대보험·건강보험료는 **2025년 요율** (메트와 맞춤). 2026년 요율로 바꿀지 결정 필요
- 순손익액은 세법상 순손익액이 아니라 법인세차감전이익을 쓰는 약식
- 주식 80% 이상 법인(54조④5호)과 개인사업자 법인전환 3년 특례는 자동 판단 안 함
- 등기부 스캔본은 줄 그은(말소) 내용을 구분하지 못함 → «사임·말소 확인» 경고로 대신함
- 다른 세무 프로그램(세무사랑 등)이 만든 조정계산서는 아직 시험하지 않음

## 시험한 자료 (실명 제외)

- 세무조정계산서 2개사
 - 제조 법인: 4개 연도, 7개월 가결산본 포함, 유상증자 후 주주 변동
 - 가족 부동산임대 법인: 자산수증이익 있음
- 법인등기부 스캔본 2건: 흰 바탕, 노란 무늬
- DART 감사보고서 1건: 외감 제조업, 공동대표, 법인 주주
- 메트라이프 기업분석리포트·컨셉제안서 수치 대조: 기업가치, 영업권, 상속세, 세금 비교, 재무비율
