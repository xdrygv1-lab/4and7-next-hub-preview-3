## 업체 분석 도구 (보내 주신 업체분석.html)

보내 주신 변경 내용(아래)은 **업체분석.html 파일**에 들어 있습니다. 이번에 받은 자료에는 이 파일이 빠져 있어서, 파일을 받는 대로 «업체 분석 → 제안 준비»에 넣어 이 미리보기에서 바로 보이게 하겠습니다.

| 들어갈 것 | 내용 |
|---|---|
| 자료 자동 입력 | 세무조정계산서, DART 감사보고서, 등기부등본(스캔본 글자 인식)으로 회사 정보·주주명부·3년 재무 채우기. 여러 해 파일을 함께 올리면 3년이 채워짐 |
| 비상장주식 가치 | «순자산 × 80%» 방식을 빼고 상증법 약식 하나로 통일 (상속세 상자·컨셉 진단·AP 07단계). 순손익은 법인세차감전이익, 평가 방식 선택(3:2 / 2:3 / 순자산 100%)과 80% 하한, 영업권 합산 제외 사유, 부동산 80% 법인(26.2.27 개정), 부동산 시가, 주주별 지분가치, 연도별 추정 |
| 상속세 | 배우자공제 최대·최소, 신고세액공제, 세후·부담률 |
| 영업 명분 | 급여·배당·퇴직금 세금 비교표, 가지급금 3년 부담표 |
| 신호등·계정 점검 | 대표 ≠ 주주, 법인 최대주주, 적자 배당, 자산수증이익, 1년 미만 사업연도, 공동대표, 연구소 인증, 퇴직연금 미적립, 인정이자 미계상 등 |
| 재무 분석 | 재무상태표 3년, 재무비율 4종(안정성·수익성·성장성·활동성), 현금창출기간 |
| 새 화법 | 급여 vs 퇴직금 차이, 법인 최대주주와의 관계, 적자인데 배당한 사정, 다른 주주 여부 질문 |
